# Scripts: what each one is for

Generated by `scripts/script_index.py` from `data/script_index.json`: descriptions use an explicit registry purpose where supplied, otherwise the script's first docstring sentence. **Tools** provide documented routes for your own inputs; linked tutorials teach those contracts. Case-study/research runners reproduce source-specific assemblies or experiments. Some supply reusable internals to tools, but their complete CLIs can retain dataset, calibration or lab assumptions. Use the tool wrapper and guide for your own records. Tests (`test_*.py`) are not listed.
