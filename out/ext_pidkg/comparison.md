# An external reader through the reader slot: pid-to-kg on the development sets

Generated by `scripts/external_reader_comparison.py`; do not edit by hand. Development sets only (OPEN100 0-5, TE revisions A and D, Pahala P-401/P-501): every number here was seen while comparing, none is a generalization claim. pid-to-kg is [Scott Duncan's public MIT skill](https://github.com/ScottDuncanAI/PID-to-Knowledge-Graph), run headless as its README describes (commit `7ee3a82`, claude-opus-5-5[1m], one run per sheet). Its graph.json enters through `scripts/reader_external_kg.py`; the adapter's rules were fixed before any score was seen, and the key converted through it scores perfect (`scripts/test_reader_external_kg.py`). It is a measured comparison and a source of ideas, not a dependency. Readings of OPEN100 sheets are CC BY-SA 4.0 derived data (`predictions/README.md`); the Pahala readings are not in this repository, only their counts.
