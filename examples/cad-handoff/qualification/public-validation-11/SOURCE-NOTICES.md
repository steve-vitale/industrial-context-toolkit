# Retained source drawing notices

Public originals and their test modifications in `evidence.tar.xz` retain their upstream
repository licensing; they are not relicensed under the toolkit's general license.

- LibreCAD/LibreCAD at `c20884671c5f4566e7494890c5060569cc8d8330`: repository GPLv2
  notice and complete GPLv2 text are retained under `raw/source-notices/LibreCAD-*`.
  Copyright notices and contributor history remain in that notice.
- qcad/qcad at `897079c2d11aaa0869f839a6cf5df8a937dbddbe`: repository GPLv3 notice
  and complete GPLv3 text are retained under `raw/source-notices/QCAD-*`.
  Its notice's separate resource exceptions remain as published.

`SELECTION.json` pins each original source path, repository revision and Git blob identity.
`raw/source-notices/URLS.json` retains the exact notice URLs. Every original editable DXF
is retained alongside its explicitly fictional test adaptation. The modifications were
made by this project on 2026-11-07: added test identity/attribute annotations, source-bound
value changes, deliberate receiving returns and separately labelled planted-loss controls.
Upstream contributors did not supply those identities or approve those changes.

The adapter, writer, native command recipes and exact derived sources are supplied in
the repository/evidence. No CAD executable, proprietary plugin, font binary, license data
or native settings contents is distributed. Digest and actual selected-file observations
describe the local receiving profile only.
