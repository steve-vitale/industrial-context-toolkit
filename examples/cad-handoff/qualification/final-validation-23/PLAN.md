# Final bounded CAD handoff validation

The original [protocol](../PROTOCOL.md) and strict/byte criteria remain unchanged.
The exposed full procedure has now been exercised: actual native UI edits,
save/close/reopen, returned files, field editability, exact model views, actual
concurrent and second revisions, planted losses and paper rendering. Native
full-save preservation and paper delivery fail on those known sources. These
failures are final evidence for those attempts; this campaign will not repair
them, alter masks/tolerances or seek a native zero by changing comparisons.

## Freeze and inputs

Develop the orchestration only on the two already exposed multi-asset inputs.
Before testing any new candidate, freeze code, methods, six newly generated
authored boundary configurations and the public selection. Source generation
and public adaptation are fixture authoring, not preservation from an earlier
file. Native configuration contents remain private; pin their identity and the
existing QCAD 3.33.1 Qt5 image. No model calls or new paid resources are needed.

Six same-author procedural cases cover R12, R2000, R2004, R2007, R2013 and R2018,
cp1252/cp1251/UTF-8, LF/CRLF/mixed endings, mirrors/rotation/nonuniform scales,
one to three assets, reversed attribute order, long/literal/non-Latin values and
foreign attributes/XDATA/raw comments. Supported paper layouts are authored with
main and display viewports. They do not repair any earlier failed source.

Select four public files from pinned upstream tree metadata: LibreCAD air/water,
mechanical kinematics and power engineering; plus an ezdxf hatch example. Within
each pool choose the minimum SHA256 of `ICT-FINAL-23:` plus upstream path after
excluding Git blobs already retained as DXF in this repository. Retain the
metadata, exclusions, selected Git blob IDs, exact originals and upstream license
notices. Do not inspect selected drawing contents before the method freeze.
Report original profile admission; use the unchanged public adaptation recipe if
identity annotations are needed. A refusal remains a result, with no substitute.
Public annotations are authored fixtures, not extracted installed identities.

## Execute and retain every result

1. Run the unchanged library-save baseline, source-preserving value candidate,
   strict comparison and independent reconstruction on all ten admitted cases.
   Publish failures; do not drop cases or change the method after reserved results.
2. On each usable candidate, plant geometry, layer and style losses, plus foreign
   attribute and XDATA losses where those records exist. Both strict and raw
   checks must detect each applicable loss. Explicitly report unavailable kinds.
   Refuse stale hashes, wrong before values, duplicate/identity changes, newline
   values, ambiguous target serialization and occupied outputs without damage.
3. Rehearse an explicit conflicting return and unrequested collateral field,
   stale proposals, selected correction and original-scope resubmission through
   the reusable receiving tool. Keep both packets, changed-basis information,
   original/returned sources and pending authority. Reproduce a portable packet.
4. On all admitted cases, run matched native no-edit and planned-edit API saves,
   close/reopen plus fresh-process source/candidate/return field reads. This is
   transfer evidence for the existing native reader/writer, not UI equivalence.
   Retain strict losses independently for both save routes.
5. Carry the predetermined public air/water case and sixth authored case through
   the unchanged actual UI baseline/edit/save/reopen and fresh four-file receiving
   method as well. Pin all exact prepared files before launch. Keep complete
   original process evidence, normal or failed; no timeout-based restart.
6. Render native source/candidate model views under identical fixed frames/profile,
   and source paper layouts where display viewports exist. Inspect actual images;
   blank output or clipped required text fails readable delivery. Existing trial
   marks and font substitution remain explicit. API/model views do not imply
   paper, full typography or engineering acceptance.
7. Freeze retained outputs/inventories and reproduce the comparisons, receiving
   briefs, controls and native/image evidence offline in CI. Audit the complete
   original objective against the resulting evidence before calling it complete.

A software result may pass while a native route remains unqualified. The final
report must say exactly which operation and inputs each result covers. Any
reserved failure used to revise a method becomes development; another reserved
case is then needed for a new claim. No human review-time savings, plant result,
company release, general DWG/intelligent-P&ID or connectivity accuracy is inferred.
