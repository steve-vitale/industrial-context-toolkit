source, never from the public original. The fixed before/after strings exercise transfer
over new source structures, not new text-language coverage. Prior long/Unicode/foreign
and layout cases remain separate obligations and retain their failures.

Freeze derived source and plan hashes in a separate commit **before** candidate or native
execution. Apply the existing raw value patcher and matched library-save baseline to every

Record the complete library/native failures, not just totals. Do not change any old method,
comparison tolerance or profile in response to these results. A used-to-fix case becomes
development; do not reuse it as fresh validation of the fix.

## Native receiving sequence

`sha256:bb4390214744897de88b2198f0cbf812aec4be42923311298e7a5e3a5646bef8`.
Use the explicitly selected configuration file from layout run 10, with before/after
digests and native selected-file self-report, and process-local Standard → DejaVu Sans.
Never alter license state, clocks, marks, font binaries or captured images.

The unchanged native batch reads each derived source/candidate, edits and exports both
default and R15 returns, destroys/reopens documents and records exact stored values plus
plain display strings. A second native process reads all retained candidates/returns.
Process exit zero alone does not prove success: every expected case and stored field must
be present, errors retained, and a new-process readback must match each exact route file.
Retain every returned DXF and compare it with the same source/plan using the frozen strict
checker and independent byte reconstruction. Native save differences remain failures.

Native source/candidate bounds are measured after the selected font profile. Render both
using the same union model bounds with 20% of maximum dimension margin (minimum two units),
2400×1600, white background, monochrome, retained trial mark. Also use union bounds per
identified asset for readable views; overviews alone cannot establish label readability.
Retain invalid/missing bounds as failures; do not silently omit an asset or substitute a
different frame to improve a result. Inspect every image. Pixel equality does not prove
editability, correct text or complete geometry, and API rendering does not fill the UI gate.

Later actual native UI edit/save/close/reopen must use this frozen cohort, retain the return
and fresh-process readback, preserve all failures and check planned/identity/foreign values.
