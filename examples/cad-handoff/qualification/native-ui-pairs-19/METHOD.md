# Native UI procedure, version 1 — exposed development

This procedure implements PLAN.md on the six already exposed sources. Freeze its source and all staged inputs
before execution. It is not a reserved result or a qualification claim.

Each independent process restores the same selected settings. Keep the observed startup window arrangement;
verify the actual Drawing View rectangle and native camera at every capture. Acknowledge only the ordinary
trial notice after its OK button becomes enabled. All clicks use current accessible control bounds; paths are
discovered anew. Retain complete compact JSON trees at each major phase, not only the selected controls.
Bind the canvas to the unique MDI document frame whose name equals the observed active file basename
(the unique Untitled frame before/after file use). Covered MDI canvases may still report showing; never
select the first Drawing View across the application. Retain the frame/path binding on each use.

Open files using the actual Open Drawing dialog and its observed All Files (*) filter. Record that choice;
do not silently change the reader. Save As must show R27 [2013] DXF Drawing [OpenDesign] (*.dxf), as observed
in preflight. A different format, unexpected dialog, ambiguous control, failed value check or collision stops
automation. The native process remains available for inspection after controller failure; no timeout restart.

The read-only helper additionally inventories native model-space attributes, their parent handles, bounds
and projected view bounds, and selected entity IDs. It cannot import, select, edit, save, export or close.
This is an explicit refinement of attribute observation, not a new document mutation route. The initial
selection must use the source's original handle. For a returned file, the helper may observe the unique
parent handle whose ICT_ID equals the original identity. Record the remapping, then select by the actual
native TH dialog and verify all displayed attributes before proceeding. No fuzzy identity matching.

For the no-edit process, open source, select the original handle, verify all three editable native fields,
deselect with the documented T,N shortcut, capture common frames, Save As to a new return, close the document,
reopen the return, reselect and verify the same values. For the edited process, use the same sequence but type
QUAL-AFTER into only MANUFACTURER and commit with Tab before deselection/save. This X11 entry recipe supports
ASCII single-line values only; these six cases have no foreign attribute. Neither limitation is a broader pass.

A fresh receiving process serially opens source, no-edit return, edited return and exact-span candidate.
It verifies filename, native attributes, UI enabled/editable state and deselected common views for each,
then closes each document through Ctrl+W. Normal external window-close ends an unmodified application.

Freeze overview, asset and label frames from the source/candidate ezdxf bounding-box union before native
execution. Padding is max(2 world units, 20% of the larger span). These are camera requests, not permission
to ignore pixels. Save full desktop images and exact native canvas crops; take consecutive images until
decoded canvas pixels agree, with ten attempts maximum. Move the pointer to (2300,1300), outside the observed
application and property editor, before every capture. Any clipping/font/geometry differences remain findings.
Later analysis must retain all changed pixels; no outcome-dependent frame or mask expansion.

Source and candidate bytes are read-only evidence. Every job binds exact sources, expected fields, frames,
configuration and methods. Capture all native action commands/results, complete UI trees, read-only replies,
screenshots, returned files, source before/after hashes and actual process status. Full-save strict differences
remain failures even when baseline and edited routes share them. Readable/editable and revision/conflict gates
remain distinct from source-preserving byte checks and public geometry coverage.

Primary UI references: [By Handle](https://qcad.org/en/manual/scripts/misc/miscselect/selectbyhandle/doc/selectbyhandle/)
and [Deselect All](https://qcad.org/en/manual/scripts/select/deselectall/doc/deselectall/).
