# One unit's portable foundation

Run the [own-input workflow and complete example](../../docs/FOUNDATION_HANDOFF.md)
with Python 3.10+ standard library, no accounts or network:

```sh
python -S examples/foundation-cycle/reproduce.py --out out/foundation-cycle
```

questions, proposed decisions, declared owners and exact originals. Actual toolkit
receiving, a document-only change, corrected exports, conflicting proposals,
missing evidence and full export/reopen are exercised. This is author-run software
evidence on fictional teaching records. It does not test a company's use, a
governed-service importer or authenticated acceptance.
